# Project Context: EDF App (PACIFIK)

This document provides a comprehensive overview of the EDF application project, including its architecture, backend, frontend, and design stack. It is intended to serve as context for AI assistants and developers.

## 1. High-Level Architecture
The project is a decoupled hybrid application consisting of:
- **Backend:** A RESTful API built with Laravel 11.
- **Frontend:** A Single Page Application (SPA) built with Vue 3, Vite, and bundled as a mobile application using Capacitor.
- **Real-time Communication:** Utilizes Laravel Reverb/Pusher and Firebase Cloud Messaging (FCM) for push notifications and real-time events.

## 2. Backend Overview
**Framework:** Laravel v11.31 (PHP ^8.2)

### Key Dependencies & Features:
- **Authentication:** Laravel Sanctum & Fortify for secure API authentication.
- **Real-time:** Pusher (`pusher/pusher-php-server`) for WebSockets.
- **Push Notifications:** Firebase (`kreait/firebase-php`, `laravel-notification-channels/fcm`).
- **Database:** Standard Laravel Eloquent ORM.
- **Testing:** Pest PHP.

### Structure:
Follows standard Laravel 11 architecture with routes, app, database, public, resources, and storage directories at the root level. The root `composer.json` defines the backend dependencies and standard Laravel scripts.

## 3. Frontend Overview
The frontend is isolated in the `frontend/` directory and acts as an independent application communicating with the backend API.

**Framework:** Vue 3 (^3.5.13)  
**Build Tool:** Vite (^6.0)  
**Mobile Wrapper:** Capacitor v7 (Android app ID: `com.edfteam.edfapp`, App Name: `PACIFIK`)

### Key Dependencies & Features:
- **State Management:** Pinia.
- **Routing:** Vue Router.
- **Real-time & WebSockets:** `laravel-echo`, `pusher-js`.
- **Push Notifications:** `@capacitor-firebase/messaging`, `@capacitor/push-notifications`.
- **Date/Time:** Moment.js.

### UI & Design Stack:
The application uses a mix of powerful UI libraries to achieve a responsive and mobile-first design:
- **Tailwind CSS:** For utility-first custom styling. The default font family configured is **Figtree**.
- **Quasar Framework (`quasar` & `@quasar/vite-plugin`):** Used for comprehensive Vue UI components.
- **Vant UI (`vant`):** A lightweight, customizable Vue UI library specifically designed for mobile web apps.
- **Custom Components:** `vue3-q-tel-input` (telephone inputs), `vue3-zoomer`.
- **Theme Colors:** The Capacitor splash screen and status bar are configured to use a dark blue/navy theme color (`#0e344c`).

### Frontend Directory Structure (`frontend/src/`):
- `resources/`
  - `assets/`: Static files, images, global styles.
  - `components/`: Reusable Vue components.
  - `layouts/`: Page wrappers and UI shells.
  - `plugins/`: Vue plugins configuration.
  - `routes/`: Vue Router definitions.
  - `services/`: API calls and external services logic.
  - `view/`: Page-level Vue components.
  - `App.vue`: Main application entry component.
  - `main.js`: Application bootstrapping.
- `app.js`, `bootstrap.js`, `echo.js`: Laravel Echo and general bootstrapping logic.

## 4. Development & Deployment
- **Backend Dev:** `php artisan serve` and `php artisan queue:listen`.
- **Frontend Dev:** `npm run dev` in the `frontend` folder (configured to run on port 8031 and host IP `192.168.1.27` or `192.168.31.117`).
- **Concurrent Dev:** The root `package.json` includes a `dev` script using `concurrently` to run the Laravel server, queue, and Vite frontend simultaneously (`npm run dev` from root).
- **Mobile Build:** The `dist` folder generated by Vite is used by Capacitor (`webDir: "dist"`) to build the Android application via Android Studio. Allow navigation rules are set for local development IPs and staging Bluehost servers.

## 5. Notes for AI Context
- When modifying the UI, prioritize using **Quasar** or **Vant** components for consistency, supplemented by **Tailwind CSS** for layout and spacing.
- Always check the `frontend/src/resources/` structure when creating or modifying Vue components or routes.
- API interactions should go through configured Axios instances (likely in `services/`).
- Real-time features are handled by Laravel Echo and should be tested using the provided dev scripts.
