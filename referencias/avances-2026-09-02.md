# Avances — 02/09/2026

## 1. Pago de Gastos (Expense Payments)

### Migraciones creadas
- `2026_09_02_000001_add_expense_id_to_pays_table.php` — `pays.expense_id` nullable FK → expenses
- `2026_09_02_000002_add_pay_id_to_expenses_table.php` — `expenses.pay_id` nullable FK → pays
- `2026_09_02_000003_make_pay_method_nullable_in_pays_table.php` — `pays.pay_method` → nullable

### Backend
- **Pay model**: `expense_id` en fillable, relación `expense()`, type=3 en `title_pay`
- **Expense model**: `pay_id` en fillable, relación `pay()`
- **Transaction model**: `expense_id` en fillable, relación `expense()`
- **PayController**: Nuevo método `storeExpensePay()` — crea Pay type=3 status=2 (Exitoso directo), Transaction type=2 (Egreso), descuenta saldo de cuenta financiera
- **Ruta**: `POST /api/expenses/{id}/pay` (admin only)

### Frontend
- **expense.store.js**: Action `payExpense(id, payload)` con `multipart/form-data`
- **expenseDetails.vue**: Botón "Registrar pago" (solo status ≠ 3), modal con: monto, cuenta financiera, categoría de transacción, referencia, fecha, vaucher opcional

### Flujo
```
Gasto status=1 → Admin registra pago → Pay type=3 status=2 → Transaction type=2 (Egreso) → Gasto status=3 (Pagado)
```

## 2. Reporte de Morosos — Fix completo

### Problemas detectados
1. **Sumas incorrectas**: Source A (usuarios moroso) mostraba `total_debt=0` sin cuotas
2. **Responsables incorrectos**: Grouping no respetaba `tenant_pays_quota`
3. **Stats no calculados**: `uniqueDelinquents` solo contaba propietarios, no inquilinos
4. **Status incompleto**: Solo buscaba status=1, no status=4 (vencida)

### Cambios en `ReportController.php`
- **`delinquents()`**: Reescritura completa — query principal con status IN [1,4], grouping por responsable real (respeta `tenant_pays_quota`), moroso users sin cuotas se agregan por separado
- **`getDelinquentsData()`**: Misma lógica para export
- **`delinquentsMetrics()`**: Fix `uniqueDelinquents` — cuenta propietarios + inquilinos responsables
- **Helpers nuevos**: `getResponsibleUserId(Quota)`, `getResponsibleUser(Quota)`

### Cambios en `reportDelinquents.vue`
- `getPaymentResponsible()`: Siempre muestra nombre del responsable, incluso en roles mixtos

## 3. Reservas — Filtro de departamentos

### Problema
Se permitían reservas con departamentos tipo estacionamiento (type=2) o depósito (type=3).

### Cambios
- **`createReserve.vue`**: Filtra `departments_inquilino` por `departament?.type == 1`
- **`BookingController::storeBooking()`**: Filtra `$residentIds` por `type = TYPE_DEPARTAMENTO`, y auto-assign también filtra por type=1

### Resultado
- Solo departamentos tipo "departamento" (type=1) se muestran en el selector
- Si el usuario tiene 1 solo → auto-seleccionado
- Si tiene múltiples → dropdown
- Backend valida que solo se permita type=1
